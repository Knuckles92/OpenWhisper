CREATION
These are promotional desktop compositions made with the built-in image_gen
tool. The app reference images were rendered from OpenWhisper's real Qt UI
using each installed Omarchy palette and disposable settings. No live theme
or desktop settings were changed on jed.

PROMPTS AND REFERENCES
The complete prompts and source links are in prompts-and-sources.json.
The local references/ folder holds the input material for future revisions.
The shareable ZIP contains the final graphics, these notes, and the prompts.
